# Тепловые и световые режимы умного дома — вариант 20

Учебный проект выделяет общие режимы температуры и влажности в доме и сопоставляет их с наружной солнечной радиацией и освещённостью комнат по набору SML2010.

## Запуск

Нужны Python 3.10+ и NumPy:

```powershell
python -m pip install -r requirements.txt
python analysis.py
```

Скрипт читает приложенные исходные файлы из `data/`, запускает PCA для всех записей, факторный анализ максимум на 2 000 строках и кластеризацию максимум на 1 200 строках. Он строит графики и сохраняет таблицы результатов в `figures/` и `results/`.

## Структура

- `analysis.py` — подготовка данных, PCA, параллельный анализ, факторный анализ главных осей с вращением Varimax, K-means и временная проверка реконструкции.
- `data/` — файлы из ZIP-архива.
- `data/README.md` — выбранные переменные, единицы, временные интервалы и атрибуция.
- `report.md` — основные выводы.
- `results/` — нагрузки, доли дисперсии, временная ошибка, факторные нагрузки и кластеры.
- `figures/` — тепловая карта нагрузок, временная динамика и график кластеров.

Дата, время, день недели и три бинарных сигнала управления не входят в PCA. Они остаются метаданными; в этой работе время используется для временного разбиения и графика динамики. Пропусков в выбранных непрерывных входах нет, поэтому заполнение будущими значениями не применяется.
